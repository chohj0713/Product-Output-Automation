# Screen Plan: 픽드랍 예약 - Biz Web

## Screen Selection Rules

- 실제 사용자가 보는 화면, 모달, 영역을 기준으로 나눈다.
- 정책은 화면 동작을 설명하는 보조 정보로만 연결한다.
- 픽드랍 등록, 픽드랍 전용 등록, 픽드랍 목록 확인은 같은 기능 안의 서로 다른 화면 상태로 관리한다.
- 빈 상태, 초과 상태, 이용권 없음, 날짜 충돌은 별도 화면이 아니라 해당 화면 영역의 상태로 묶는다.

## Final Screen List

| Screen ID | Platform | Screen | Primary User Goal | Entry Path | Main Screen Areas | Priority |
| --- | --- | --- | --- | --- | --- | --- |
| S-01 | Biz Web | 유치원 예약 목록 | 선택한 날짜의 예약과 픽드랍 대상자를 확인한다. | 유치원 메인 예약 화면 | 월간 캘린더, 예약 목록, 픽드랍 목록 모달 | High |
| S-02 | Biz Web | 예약 등록 모달 - 유치원/데이케어 단계 | 회원, 서비스, 픽드랍 여부, 날짜를 선택해 예약 초안을 만든다. | 예약 등록 > 유치원 또는 데이케어 | 회원 검색, 진행 단계, 서비스/픽드랍 선택, 날짜 선택, 예약 횟수, 메모, 요금 요약 | High |
| S-03 | Biz Web | 예약 등록 모달 - 픽드랍 단계 | 기존 예약 날짜 또는 별도 픽드랍 날짜에 픽드랍을 함께 등록한다. | 예약 등록 모달 > 픽드랍까지 예약 | 잠긴 회원 영역, 픽드랍 날짜 선택, 픽드랍 이용권, 픽드랍 요금, 등록 버튼 | High |

## Screen Area Plan

| Screen ID | Screen Area | UI Items | Behaviors / States To Cover | Policy Notes Needed |
| --- | --- | --- | --- | --- |
| S-01 | 예약 목록 헤더 | 선택일, 예약 수, 픽드랍 목록 버튼 | 선택 날짜 기준으로 목록을 열고 픽드랍 모달의 초기 날짜를 맞춘다. | 목록은 선택 날짜의 예약 엔트리 기준 |
| S-01 | 픽드랍 목록 모달 | 날짜 이동, 날짜 입력, 픽업/드랍 필터, 대상자 카드 | 날짜와 필터에 맞는 보호자/반려견/주소를 표시하고 빈 상태를 제공한다. | 픽업과 드랍을 모두 켜면 두 조건을 모두 가진 가구만 표시 |
| S-02 | 회원/서비스 선택 | 회원 검색, 클래스 라디오, 데이케어 시간 | 회원 선택 후 이용권과 클래스 후보를 갱신한다. 데이케어는 시간과 요금 행을 노출한다. | 데이케어 시간 중복은 저장 전 차단 |
| S-02 | 픽드랍 선택 | 픽업 체크박스, 드랍 체크박스 | 서비스 예약 날짜에 픽드랍 플래그와 요금/이용권 사용 계획을 연결한다. | 픽업+드랍은 왕복, 한쪽만 선택하면 편도 |
| S-02 | 날짜/횟수 | 미니 캘린더, 예약 가능 횟수, 초과 등록 체크 | 날짜 선택, 이용권 요일 자동 선택, 충돌일 비활성, 초과 상태를 표시한다. | 초과 등록 체크 시 서비스 단계 등록 허용 |
| S-02 | 요금/결제 | 예상 금액, 이용권 탭, 현장 결제 탭, 잔액 | 서비스와 픽드랍 요금을 분리 표시하고 결제 방식에 따라 잔액을 계산한다. | 이용권 결제는 결제 금액을 기대 금액으로 처리 |
| S-03 | 픽드랍 단계 전환 | 이전 버튼, 등록 버튼, 진행 단계 | 픽드랍 단계에서 회원은 잠그고 서비스 영역은 접고 픽드랍 영역을 연다. | 픽드랍 초과는 별도 초과 체크 없이 등록 가능 |
| S-03 | 픽드랍 이용권/저장 | 픽드랍 이용권 목록, 날짜, 등록 | 편도/왕복 이용권을 날짜별로 차감하고 예약 엔트리를 날짜별 예약으로 저장한다. | 왕복 이용권 우선, 부족 시 편도 2장 사용 |

## Grouped Edge States

| Edge State | Parent Screen Area | Reason |
| --- | --- | --- |
| 픽드랍 목록 결과 없음 | S-01 / 픽드랍 목록 모달 | 조건에 맞는 회원이 없는 상태 메시지로 처리한다. |
| 픽드랍 필터 모두 해제 | S-01 / 픽드랍 목록 모달 | 필터가 0개가 되면 픽업/드랍을 다시 모두 활성화한다. |
| 날짜 충돌 | S-02 / 날짜/횟수 | 캘린더 셀 비활성으로 처리하고 선택 대상에서 제외한다. |
| 예약 가능 횟수 초과 | S-02 / 날짜/횟수 | 오류 문구와 초과 등록 체크박스로 처리한다. |
| 사용 가능한 픽드랍 이용권 없음 | S-03 / 픽드랍 이용권/저장 | 픽드랍 이용권 영역의 빈 상태로 처리한다. |
| 데이케어 시간 누락/역전/중복 | S-02 / 회원/서비스 선택 | 토스트와 저장 차단으로 처리한다. |
