## Context - S-01

유치원 운영자는 월간 캘린더에서 날짜를 선택하고, 해당 날짜의 예약 목록을 확인한다. 예약 목록 안의 `픽드랍 목록` 버튼은 선택한 날짜에 픽업 또는 드랍이 포함된 예약을 모아 별도 모달로 보여준다.

정책은 목록의 표시 조건을 보조한다. 픽드랍 여부는 예약 엔트리의 픽업/드랍 상태에서 판단하며, 목록은 보호자와 반려견 단위로 운영자가 이동 대상을 확인할 수 있게 구성된다.

## Policy Notes - S-01

- 픽드랍 목록은 예약 엔트리의 픽업/드랍 플래그를 기준으로 산출한다.
- 픽업과 드랍 필터가 모두 켜진 경우, 두 타입을 모두 가진 가구만 표시한다.
- 대상자 카드는 예약 회원 정보가 있으면 회원 데이터를 우선 사용하고, 없으면 예약에 저장된 보호자/반려견 정보를 사용한다.

## Context - S-02

운영자는 예약 등록 모달에서 회원을 먼저 선택하고, 회원이 보유한 이용권과 클래스 정보를 바탕으로 예약 날짜를 정한다. 픽업 또는 드랍 체크박스는 서비스 예약 날짜에 픽드랍을 함께 붙이는 기본 선택 영역이다.

이 화면은 예약의 기본 정보를 만드는 단계다. 픽드랍만 별도 날짜로 추가하려면 `픽드랍까지 예약`을 눌러 S-03의 픽드랍 단계로 이동한다.

## Policy Notes - S-02

- 픽업과 드랍이 모두 선택되면 왕복 기준, 하나만 선택되면 편도 기준으로 요금과 이용권 차감을 계산한다.
- 서비스 이용권은 선택한 클래스와 연결된 이용권을 우선 사용한다.
- 이용권 요일 규칙이 있으면 자동 날짜 선택 후보에 반영하고, 휴무일과 충돌일은 제외한다.
- 예약은 최종 저장 시 날짜 엔트리별 예약으로 분리되어 저장된다.
- 이용권 결제는 실제 결제 금액 입력 없이 이용권 사용분으로 결제 상태를 구성한다.

## Context - S-03

픽드랍 단계는 서비스 예약과 이어서 픽드랍을 등록하거나, 회원 선택 후 픽드랍만 별도로 예약하는 화면 상태다. 진입하면 회원 영역은 잠기고, 진행 단계는 픽드랍으로 이동하며, 서비스 요금/이용권 영역은 접히고 픽드랍 요금/이용권 영역이 열린다.

서비스 예약 날짜가 이미 선택되어 있으면 해당 날짜가 픽드랍 날짜의 초기값이 된다. 픽드랍 가능 횟수가 적으면 초기 픽드랍 날짜를 가능 횟수만큼 자른다.

## Policy Notes - S-03

- 픽드랍 단계에서 픽업+드랍은 왕복 이용권 1장을 우선 사용한다.
- 왕복 이용권이 부족하면 편도 이용권 2장으로 대체 사용한다.
- 픽업 또는 드랍 한쪽만 선택한 경우 편도 이용권 1장을 우선 사용하고, 없으면 왕복 이용권 1장을 fallback으로 사용할 수 있다.
- 서비스 날짜가 없는 픽드랍 전용 예약은 클래스/서비스 값 없이 픽드랍 날짜 엔트리로 저장된다.
- 저장 후 회원의 편도/왕복 예약 가능 횟수와 이용권 사용량을 함께 갱신한다.
