## Context - S-01

운영자는 예약 목록에서 날짜를 선택한 뒤 `픽드랍 목록`을 열어 해당 날짜에 픽업 또는 드랍이 필요한 회원을 확인한다. 이 모달은 예약을 수정하는 화면이 아니라, 선택 날짜의 픽드랍 운영 대상을 조회하는 화면이다.

목록은 예약 date entry의 픽업/드랍 여부를 기준으로 구성된다. 필터는 픽업과 드랍을 독립적으로 켜고 끌 수 있으며, 결과는 보호자와 반려견 단위로 확인할 수 있어야 한다.

## Policy Notes - S-01

- 픽드랍 목록은 예약 날짜별 entry의 `pickup`, `dropoff` 상태를 기준으로 산출한다.
- 픽업과 드랍 필터를 모두 끄는 상태는 유지하지 않고 전체 필터 상태로 복구한다.
- 대상자 정보는 회원 데이터가 있으면 회원 정보를 우선 표시하고, 없으면 예약에 저장된 정보를 사용한다.

## Context - S-02

운영자는 예약 등록 모달에서 회원을 먼저 선택한 뒤 클래스 또는 데이케어 서비스를 선택하고 예약 날짜를 지정한다. 같은 단계에서 픽업/드랍 체크박스를 켜면 서비스 예약 날짜에 픽드랍을 함께 붙일 수 있다.

하단의 `픽드랍까지 예약` 버튼은 현재 입력값을 유지한 채 픽드랍 단계로 전환한다. 서비스 날짜가 선택되어 있으면 해당 날짜가 픽드랍 날짜의 초기값이 되고, 서비스 날짜가 없으면 픽드랍만 예약하는 흐름으로 진입한다.

## Policy Notes - S-02

- 픽업과 드랍을 모두 선택하면 왕복 기준, 하나만 선택하면 편도 기준으로 요금과 이용권 차감을 계산한다.
- 서비스 단계의 초과 예약은 초과 등록 체크가 있어야 저장할 수 있다.
- 픽드랍 요금은 선택된 픽드랍 종류와 픽드랍 적용 날짜 수를 기준으로 계산한다.
- 이용권 결제는 실제 금액 입력 없이 이용권 사용 상태로 결제 요약을 구성한다.
- 예약 저장 시 날짜별 예약 entry로 분리되며, 각 entry에 서비스 이용권 사용과 픽드랍 이용권 사용이 병합된다.

## Context - S-03

픽드랍 단계는 서비스 예약에 이어 픽드랍을 함께 등록하거나, 서비스 날짜 없이 픽드랍만 등록하는 단계다. 이 단계로 진입하면 회원 영역은 잠기고 진행 단계는 픽드랍이 활성화된다.

서비스 단계에서 이미 날짜를 선택했다면 해당 날짜가 픽드랍 날짜의 초기값으로 복사된다. 회원의 픽드랍 가능 횟수가 초기 날짜 수보다 적으면 가능한 횟수만큼만 초기 선택된다. 운영자는 픽업/드랍 종류와 픽드랍 날짜, 픽드랍 이용권을 조정한 뒤 등록한다.

## Policy Notes - S-03

- 픽업+드랍은 왕복 이용권 1회를 우선 사용한다.
- 왕복 이용권이 부족하면 편도 이용권 2회를 대체 사용한다.
- 픽업 또는 드랍 하나만 선택한 경우 편도 이용권 1회를 우선 사용하고, 없으면 왕복 이용권 1회를 대체 사용할 수 있다.
- 서비스 날짜가 없는 픽드랍 전용 예약은 서비스명 없이 픽드랍 플래그와 픽드랍 이용권 사용만 포함한 날짜 entry로 저장된다.
- 저장 후 회원의 서비스 가능 횟수와 픽드랍 가능 횟수는 각각 서비스 타입과 편도/왕복 타입별로 갱신된다.
