## 1. 개요

픽드랍 예약은 일반 서비스 예약 또는 호텔링 예약에 픽업/하원 이동 서비스를 함께 예약하고, 선택한 이동 옵션에 따라 금액과 이용권 차감을 반영하는 기능이다.

기능은 다음 흐름을 포함한다.

- 픽드랍 대상 목록 확인
- 일반 예약 등록 중 픽드랍 예약 모드 진입
- 픽업/하원 옵션 선택
- 픽드랍 이용 날짜 선택
- 편도/왕복 기준 금액 계산
- 픽드랍 이용권 선택 및 차감
- 서비스 예약과 픽드랍 예약을 함께 저장
- 기존 예약 상세에서 픽드랍 정보 표시/수정
- 호텔링 예약과 픽드랍 옵션 연계

## 2. 공통 정책

### 2.1 픽드랍 타입

| 항목 | 명세 |
| --- | --- |
| 편도 | 픽업 또는 하원 중 하나만 선택한 상태 |
| 왕복 | 픽업과 하원을 모두 선택한 상태 |
| 선택 없음 | 픽드랍 금액과 픽드랍 이용권 차감 대상이 아님 |

### 2.2 픽드랍 옵션

- 픽업과 하원은 서로 독립적으로 선택할 수 있다.
- 픽업과 하원을 동시에 선택할 수 있다.
- 픽업만 선택하면 편도 예약으로 처리한다.
- 하원만 선택하면 편도 예약으로 처리한다.
- 픽업과 하원을 모두 선택하면 왕복 예약으로 처리한다.

### 2.3 픽드랍 날짜

- 픽드랍 날짜는 일반 서비스 예약 날짜와 별도로 관리한다.
- 픽드랍 모드에 처음 진입하면 기존에 선택한 서비스 예약 날짜를 픽드랍 날짜 기본값으로 사용한다.
- 사용자가 픽드랍 날짜를 직접 변경하면 이후에는 자동 초기화하지 않는다.
- 회원의 픽드랍 가능 횟수보다 초기 선택 날짜가 많으면 가능한 범위까지만 기본 선택한다.

### 2.4 픽드랍 이용권

- 픽드랍 예약에서는 픽드랍 유형의 이용권만 선택 대상으로 표시한다.
- 일반 서비스 이용권과 픽드랍 이용권은 서로 다른 선택 영역으로 관리한다.
- 픽드랍 이용권이 없거나 사용 가능한 횟수가 없으면 빈 상태를 표시한다.
- 초과 예약 허용 여부는 운영 정책 확인이 필요하다.

## 3. 픽드랍 목록

### 상황

관리자가 특정 날짜의 픽드랍 대상을 확인하거나 픽드랍 예약 등록 흐름으로 진입한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 목록 기본 정책 | 픽드랍 목록은 날짜 기준으로 조회한다. 목록은 픽업/하원 필터를 제공한다. 목록 조회와 예약 등록은 별도 흐름으로 분리한다. |
| 1 | 날짜 이동 | 이전 날짜, 다음 날짜, 날짜 직접 선택을 제공한다. 날짜가 변경되면 해당 날짜 기준으로 목록을 갱신한다. |
| 2 | 픽업/하원 필터 | 픽업과 하원 필터를 각각 켜고 끌 수 있다. 기본값은 둘 다 선택된 상태로 둔다. |
| 3 | 목록 빈 상태 | 선택한 날짜와 필터 조건에 해당하는 픽드랍 대상이 없으면 빈 상태 문구를 표시한다. |
| 4 | 예약 등록 진입 | 픽드랍 예약을 새로 등록할 수 있는 예약 등록 흐름으로 진입할 수 있다. |

## 4. 일반 예약 등록 중 픽드랍 모드

### 상황

관리자가 일반 서비스 예약을 등록하다가 픽드랍 예약을 함께 추가한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 모드 전환 | 예약 등록 모달은 일반 서비스 예약 모드와 픽드랍 예약 모드를 전환할 수 있다. 픽드랍 모드로 전환해도 이미 선택한 회원, 서비스, 서비스 날짜는 유지한다. |
| 1 | 진입 버튼 | 서비스 날짜가 선택되어 있으면 버튼 문구는 픽드랍까지 예약 의미로 표시한다. 서비스 날짜가 없으면 픽드랍만 예약 의미로 표시한다. |
| 2 | 진행 상태 | 픽드랍 모드에 진입하면 진행 표시에서 픽드랍 단계가 활성화된다. 일반 서비스 단계와 픽드랍 단계가 구분되어야 한다. |
| 3 | 표시 영역 전환 | 픽드랍 모드에서는 픽드랍 금액 영역과 픽드랍 이용권 영역을 표시한다. 일반 서비스 예약에만 필요한 영역은 접거나 비활성 상태로 전환한다. |
| 4 | 모드 해제 | 저장 완료, 모달 종료, 이전 단계 이동 시 픽드랍 모드를 해제한다. 다음 예약 등록에 이전 픽드랍 상태가 남아서는 안 된다. |

## 5. 픽드랍 옵션 및 날짜 선택

### 상황

관리자가 픽드랍 예약에 필요한 픽업/하원 옵션과 픽드랍 이용 날짜를 선택한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 선택 범위 | 픽드랍 옵션과 픽드랍 날짜는 일반 서비스 선택값과 별도로 관리한다. |
| 1 | 픽업 선택 | 픽업을 선택하면 선택된 픽드랍 날짜에 픽업 예약이 포함된다. 픽업을 해제하면 이후 계산과 저장 대상에서 픽업을 제외한다. |
| 2 | 하원 선택 | 하원을 선택하면 선택된 픽드랍 날짜에 하원 예약이 포함된다. 하원을 해제하면 이후 계산과 저장 대상에서 하원을 제외한다. |
| 3 | 날짜 기본값 | 픽드랍 모드 최초 진입 시 일반 서비스 날짜를 픽드랍 날짜 기본값으로 복사한다. 단, 회원의 픽드랍 가능 횟수를 초과하는 날짜는 기본 선택하지 않는다. |
| 4 | 날짜 직접 변경 | 사용자가 픽드랍 날짜를 직접 선택/해제하면 픽드랍 날짜는 사용자의 선택을 우선한다. 이후 일반 서비스 날짜 변경이 픽드랍 날짜를 자동으로 덮어쓰지 않는다. |
| 5 | 선택 없음 | 픽업과 하원이 모두 선택되지 않으면 픽드랍 금액과 이용권 차감 대상이 없으므로 저장 가능 여부를 재계산한다. |

## 6. 금액 계산

### 상황

픽드랍 옵션과 날짜 선택 결과를 기준으로 예상 금액을 계산한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 계산 기준 | 픽드랍 금액은 픽드랍 날짜 수와 편도/왕복 타입을 기준으로 계산한다. |
| 1 | 편도 금액 | 픽업 또는 하원 중 하나만 선택한 날짜는 편도 금액을 적용한다. |
| 2 | 왕복 금액 | 픽업과 하원을 모두 선택한 날짜는 왕복 금액을 적용한다. |
| 3 | 총액 반영 | 픽드랍 금액은 일반 서비스 금액과 구분해 표시하되, 최종 결제 총액에는 함께 반영한다. |
| 4 | 금액 없음 | 가격표에 필요한 금액이 없거나 픽드랍 선택이 없으면 픽드랍 금액은 0원 또는 빈 상태로 표시한다. |

## 7. 이용권 차감

### 상황

픽드랍 예약에 사용할 이용권을 선택하고, 선택된 옵션에 맞게 이용권 사용량을 계산한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 이용권 구분 | 픽드랍 이용권은 편도 이용권과 왕복 이용권을 구분한다. |
| 1 | 편도 차감 | 편도 예약은 편도 이용권 1회를 우선 차감한다. 편도 이용권이 부족하면 왕복 이용권 1회로 대체 차감할 수 있다. |
| 2 | 왕복 차감 | 왕복 예약은 왕복 이용권 1회를 우선 차감한다. 왕복 이용권이 부족하면 편도 이용권 2회로 대체 차감할 수 있다. |
| 3 | 날짜별 차감 | 여러 날짜를 선택한 경우 날짜별로 필요한 이용권 사용량을 계산한다. |
| 4 | 잔여 횟수 표시 | 픽드랍 이용권 선택 영역은 선택 전 총 사용 가능 횟수와 선택 후 예상 잔여 횟수를 보여준다. |
| 5 | 부족 상태 | 이용권이 부족한 경우 저장을 차단할지, 초과 예약으로 허용할지 정책 확인이 필요하다. |

## 8. 저장 정책

### 상황

관리자가 일반 서비스 예약만 저장하거나 픽드랍 예약까지 함께 저장한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 저장 분기 | 일반 서비스만 저장하는 경우와 픽드랍까지 포함해 저장하는 경우를 구분한다. |
| 1 | 서비스 날짜와 겹치는 픽드랍 | 픽드랍 날짜가 일반 서비스 날짜와 같으면 같은 날짜 예약 정보에 픽업/하원 정보를 함께 저장한다. |
| 2 | 픽드랍 단독 날짜 | 픽드랍 날짜가 일반 서비스 날짜에 포함되지 않으면 픽드랍만 있는 날짜 예약 정보를 별도로 추가한다. |
| 3 | 이용권 사용 내역 | 일반 서비스 이용권 사용 내역과 픽드랍 이용권 사용 내역은 같은 날짜 안에서 병합해 저장한다. |
| 4 | 저장 후 상태 | 저장이 끝나면 픽드랍 모드와 임시 선택 상태를 초기화한다. |
| 5 | 저장 실패 | 필수 선택값 누락, 이용권 부족, 한도 초과 등 저장 불가 상태에서는 저장을 막고 사용자가 원인을 알 수 있어야 한다. |

## 9. 상세 조회 및 수정

### 상황

관리자가 기존 예약 상세에서 픽드랍 정보를 확인하거나 수정한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 상세 표시 | 예약 상세에는 날짜별 픽업/하원 여부와 픽드랍 이용권 사용 내역을 표시한다. |
| 1 | 기존 선택 복원 | 기존 예약에 픽드랍 정보가 있으면 상세 화면에서 픽업/하원 선택 상태를 복원한다. |
| 2 | 이용권 후보 | 수정 시에는 해당 회원이 사용할 수 있는 픽드랍 이용권만 후보로 표시한다. |
| 3 | 사용량 재계산 | 픽업/하원 또는 날짜가 바뀌면 픽드랍 이용권 사용량을 다시 계산한다. |
| 4 | 기존 서비스 사용량 유지 | 수정 중에도 일반 서비스 이용권 사용 내역은 유지하고, 픽드랍 이용권 사용 내역만 재구성한다. |
| 5 | 후보 불일치 | 기존 예약에 저장된 픽드랍 이용권이 현재 회원의 사용 가능 후보에 없으면 재할당 또는 확인이 필요하다. |

## 10. 호텔링 연계

### 상황

관리자가 호텔링 예약을 등록하거나 수정하면서 픽드랍 옵션을 함께 설정한다.

### 기능 요구사항

| No. | 항목 | 명세 |
| --- | --- | --- |
| P | 호텔링 연계 정책 | 호텔링 예약에서도 픽업/하원 옵션, 픽드랍 금액, 픽드랍 이용권 선택을 제공한다. |
| 1 | 체크인 픽업 | 픽업을 선택하면 호텔링 체크인 날짜에 픽업 정보를 연결한다. |
| 2 | 체크아웃 하원 | 하원을 선택하면 호텔링 체크아웃 날짜에 하원 정보를 연결한다. |
| 3 | 금액 합산 | 호텔링 금액과 픽드랍 금액은 구분해 표시하되, 최종 총액에는 함께 반영한다. |
| 4 | 이용권 차감 | 호텔링 이용권과 픽드랍 이용권은 별도로 선택하고, 저장 시 날짜별 사용 내역으로 결합한다. |
| 5 | 상세 수정 | 호텔링 상세 수정 시 기존 픽드랍 선택 상태를 복원하고, 변경된 선택에 맞춰 픽드랍 사용량을 다시 계산한다. |

## 11. 예외 및 제약 조건

| 항목 | 명세 |
| --- | --- |
| 픽드랍 가능 횟수 없음 | 픽드랍 이용권 영역은 빈 상태를 표시한다. 저장 가능 여부는 정책에 따라 차단 또는 초과 허용으로 처리한다. |
| 픽드랍 옵션 미선택 | 픽업/하원이 모두 선택되지 않으면 픽드랍 금액과 차감은 발생하지 않는다. |
| 날짜 미선택 | 픽드랍 옵션이 선택되어 있어도 픽드랍 날짜가 없으면 저장할 픽드랍 대상이 없다. |
| 이용권 부족 | 부족 상태를 사용자에게 명확히 보여줘야 한다. 저장 차단 여부는 정책 확정이 필요하다. |
| 가격 정보 없음 | 금액 계산이 불가능한 경우 금액 없음 상태를 표시하고 저장 가능 여부를 재계산한다. |
| 상세 수정 중 후보 불일치 | 기존 이용권 사용 내역이 현재 후보와 맞지 않으면 재할당 또는 확인이 필요하다. |
| 호텔링 왕복 | 호텔링에서 픽업+하원을 선택한 경우 왕복 1회 차감인지 편도 2회 차감인지 정책 확정이 필요하다. |

## 12. Open Questions

- 픽드랍 이용권 부족 상태에서 저장을 차단할지, 초과 예약으로 허용할지 결정이 필요하다.
- 호텔링에서 픽업과 하원을 모두 선택한 경우 왕복 이용권 1회로 볼지, 체크인/체크아웃 각각 편도 1회로 볼지 결정이 필요하다.
- 픽업만 선택한 편도와 하원만 선택한 편도를 사용자 화면에서 같은 편도로 표시할지, 픽업 편도/하원 편도로 구분할지 결정이 필요하다.
- 가격 정보가 없는 픽드랍 옵션을 저장 가능하게 둘지, 금액 설정 전까지 차단할지 결정이 필요하다.
